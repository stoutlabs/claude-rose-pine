# Rosé Pine

A Rosé Pine look for the Claude desktop and mobile apps, built from the palettes at rosepinetheme.com.

- **Light mode:** Rosé Pine Dawn.
- **Dark mode:** Rosé Pine (main) by default, or Rosé Pine Moon.

Switch the dark variant with `/rose-pine main` or `/rose-pine moon`. The choice is remembered across sessions. Run `/rose-pine` on its own to see which variant is active. The terminal and editors don't draw themes, so this only changes the apps.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install rose-pine --marketplace stoutlabs/claude-rose-pine
```

Answer `y` to add the marketplace, then press Enter to pick the user scope.

From a shell:

```bash
claude plugin install rose-pine --marketplace stoutlabs/claude-rose-pine
```

In the desktop app, where `/plugin` does not run: click **+** next to the prompt box, then **Plugins**, then **Add marketplace** with `stoutlabs/claude-rose-pine`, then **Add plugin**.
